# DatAIJam

Sitio web de **DatAIJam**, la conferencia de datos e inteligencia artificial con un hackathon de 4 semanas en Guayaquil, Ecuador.

**→ [dataijam.com](https://dataijam.com)**

## Tecnologías

React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion

## Correrlo en local

Necesitas Node 22.12+ y pnpm 11.

```bash
git clone https://github.com/SKEIILATT/dataijam.git
cd dataijam
pnpm install
pnpm dev
```
